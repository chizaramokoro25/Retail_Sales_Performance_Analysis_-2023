# Project Overview 
This project focuses on analysing retail transactions to determine how revenue changes over time, whether seasonal patterns exist, which regions and product categories perform best, and who are the highest value customers. The data was cleaned and validated in Excel and Power Query, loaded into PostgreSQL, and queried with SQL(aggregations, CTEs, etc) to calculate revenues, units sold, seasonal indices and month-over-month change. Results were visualised in an interactive Excel dashboard. A data quality assessment documents the issues found and the decsions made.  

Project Objectives
- Analyse overall sales performance
- identify sales trend and patterns
- evaluate product category performance
- identify key business insights from the available data
- present findings through clear and meaningful visualisations

Tools & Technologies
- Data Cleaning: Excel
- Data Analysis: SQL
- Data Visualisation: Excel
- Documentation: MS Word
